# Xe Buýt Sài Gòn 🚌

Game quản lý mạng lưới xe buýt TP.HCM trên trình duyệt điện thoại, dùng **tuyến và trạm xe buýt thật** từ OpenStreetMap.

- Dữ liệu tuyến/trạm: © OpenStreetMap contributors (ODbL), lấy qua Overpass API.
- Bản đồ nền: OpenFreeMap (OpenMapTiles, © OpenStreetMap contributors).
- Xem đầy đủ nguồn ảnh và giấy phép trong [CREDITS.md](CREDITS.md).

Trang tĩnh (HTML/JS/CSS), không cần build. Chạy thử: `python3 -m http.server` rồi mở trình duyệt.
